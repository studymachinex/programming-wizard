`<`, `<=`, `>` e `>=` só comparam números — nem strings: `Operands must be numbers.`

## O que você vai aprender

- a fechar a semântica das expressões.

## O que fazer

Valide os operandos dos relacionais.

## Como o tester valida

- string < número, `true >= false`, `"a" > "b"`.

## Dicas

- Erros de execução: imprima a mensagem no stderr e, na linha seguinte, `[line N]`; termine com código **70**.

## Critério de conclusão

Expressões estão completas, com erros de execução.
